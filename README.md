# INFO
Приложение для помощи в изучении иностранных слов.
[![Работа приложения]](https://notoriginalnickname.github.io/word-frequency-analyzator/presentation/presentation.mp4)
**Проблема**
При изучении языка наступает этап, когда уже есть базовый вокобуляр и для его расширения нужно смотреть видео или читать тексты. Но, как правило, встречается очень много незнакомых слов и заучивать все непродуктивно

**Решение в виде этого приложения**
Продолжать смотреть или читать, записывая слова столько раз, сколько они попадаются. Приложение само подсчитает наиболее частые слова, которые следовательно будут вам более полезны, так как попадаются чаще других
